# Universal Service Manager — capabilities

USM brings everyday application and host administration into one workspace. Use this guide to find the area that matches the task, then see the [product presentation](README.md) for the illustrated tour.

## Run and organise applications

- **Services:** inspect status and recent resource use; start, stop or restart an application; open its logs.
- **Groups and filters:** organise related workloads, search the fleet and narrow the view to active services.
- **Overview:** compare applications in a compact table and sort to find the entries that need attention.
- **Recovery:** support automatic recovery for eligible unexpected stops while retaining deliberate maintenance controls.
- **Command-line access:** work from a terminal when a browser is unnecessary.

These controls reduce the effort of maintaining a mixed fleet whose applications would otherwise need separate launch and inspection routines.

## Investigate a problem

- **Logs:** select a service, filter messages, search output and pause or follow the view.
- **Resources:** inspect CPU, memory, storage and network activity together; compare application usage.
- **Processes:** search the host's running workloads, inspect related processes and register existing workloads for monitoring.
- **Debug:** review health summaries, resource alerts, restart activity and recent operation results.

Move from the symptom to supporting information without switching between several utilities. Copy and download options help retain log findings for further work.

## Manage the surrounding platform

- **Docker:** inspect containers, output and resource use; manage images, networks and volumes.
- **Compose:** operate multi-container applications through project-level controls.
- **Systemd:** find native system and user services, inspect their journals and manage lifecycle or boot enablement.
- **Startup:** review the available boot mechanisms together.
- **Firewall:** inspect firewall state, rules and recent events; maintain rules when supported by the host.

Keeping these areas beside the applications helps investigate problems that involve more than the application itself.

## Connect and maintain

- **Connections:** inspect remote destinations and connection readiness, then navigate local and remote files side by side.
- **File transfers:** copy in either direction, upload or download, and follow progress.
- **Configuration:** validate and maintain service definitions within the dashboard.
- **Settings:** adapt appearance, logs, refresh behaviour, alerts, privacy and confirmation prompts.
- **Preference portability:** export and import the dashboard setup between browser profiles.

Features remain useful even when they do not appear in the supplied screenshots. The goal is a consistent daily workspace for running, inspecting and maintaining applications.
